2. 课程说明与更新
Course Description and Updates
咖啡导论课程为新进咖啡专业人士与消费者提供精品咖啡价值链的概论，并介绍历史、种植、
处理、烘焙、感官评估以及冲煮准备的核心概念。学员将通过多样化的品鉴练习，深入了解价
值链中各项决策如何影响最终的咖啡风味。Introduction to Coffee provides new coffee professionals and
consumers with a general overview of the specialty coffee value chain and introduces key concepts in history,
cultivation, processing, roasting, sensory assessment, and preparation. Participants will engage in a variety of
tasting exercises to deepen their understanding of how decisions made along the value chain impact the final cup.
课程大纲更新与上一版本的区别：Curriculum Updates from Previous Version:
上一版本的课程指南为 2.0 版。本课程指南版本为 3.0 版。The previous guidebook version is now
referred to as Version 2.0. This guidebook version is referred to as Version 3.0.
3.0 版课程内容调整以反映精品咖啡产业的最新发展，包括咖啡价值评估。有关阿拉比卡与罗
布斯塔咖啡、感官评估，以及冲煮的章节在新版也有所优化。新版本的格式设计提升了可读
性，并新增了参考材料，有助于讲师设计教材。此外，考题也经过重新编写，使内容更加清晰
易懂。In Version 3.0, the content has been adjusted to reflect recent developments in the specialty coffee
industry, including Coffee Value Assessment. Sections on arabica and robusta, sensory assessment, and brewing
have been refined. New formatting has been applied to increase readability, references have been added to help
trainers develop their teaching materials, and exam questions have been rewritten to improve clarity.

活动：品尝精品咖啡Activity: Specialty Tasting
使用滴滤式咖啡机或手冲器材冲泡两款咖啡。这两款咖啡应展现出明显不同的感官属性（例
如：一款咖啡可能带有坚果、可可以及烘焙风味，而另一款咖啡则带有水果与花香风味）。
这两款咖啡不应有任何瑕疵，提供至少其中一款咖啡的一些外在信息，並将样品编码，以确
保学员在活动的第一阶段无法得知咖啡的背景信息。Brew two coffees using a batch brewer or
manual device. The coffees should display noticeably different sensory attributes (e.g., one coffee may contain
nutty, cocoa, and roasted flavors, while the other coffee may contain fruity and floral flavors). The coffees should
not contain defects. Some extrinsic information should be available for at least one of the coffees. Code each
sample so that learners don’t have any background information about the coffees during the first part of the
activity.
首先，请学员品尝这两款咖啡并思考下列问题：根据咖啡的描述性风味特征，哪款咖啡更像
