## 🔍 如何使用

### 在 SKILL.md 中引用
当用户询问特定主题时，直接读取对应的 Markdown 文件：

```markdown
## 世界咖啡师大赛规则查询
读取：knowledge-base/world-coffee-championships-2026/markdown/2025-WBC-Rules.md

## 水质相关问题
读取：knowledge-base/水质/markdown/water-for-coffee-CN.md
```

### 快速定位
- 大赛规则 → `world-coffee-championships-2026/markdown/`
- 水质问题 → `水质/markdown/`
- 品牌信息 → `八平方品牌手册-2025.md`
- 培训体系 → `AST-Handbook-2025.md`
