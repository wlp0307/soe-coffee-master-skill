咖啡设定表 – 说明与范例
Coffee Keys – Instructions and Example
请填写下方表格，记录您计划在面授课程中每个练习所使用的咖啡。更多详细资讯，
请参阅讲师指南中的活动描述和附录B。Fill in the tables below to track the coffees you plan to
use for each exercise in the in-person course. For more details, review the activity descriptions and Appendix B in the trainer
guidebook.
第一组活动 – 描述性、情感性、外在 First Set of Sessions – Descriptive, Affective, Extrinsic
在描述性#1 栏位中，列出您将在描述性评估#1 (第 1 天) 使用的咖啡，并包含您将用于标记每个
样品的代码。相同的咖啡将用于情感性杯测 (第 2 天)，并在情感性栏位中，列出您在情感性杯测
中用于标记每个样品的代码。In the DESCRIPTIVE#1 column, list the coffees you will use in Descriptive Assessment
#1 (Day 1). Include the codes you will use to label each sample. The same coffees will be used in the Affective Cupping (Day
2). In the AFFECTIVE column, list the codes you will use to label each sample during the Affective Cupping.
在外在栏位中，标明您将与外在故事配对的咖啡。第一个故事配对一款咖啡，第二个故事配对另
一款咖啡，其馀咖啡不提供外在信息。In the EXTRINSIC column, identify the coffees you will pair with the
extrinsic stories. Assign one story to one coffee and the second story to a different coffee. The remaining coffees will have
no extrinsic information.
第二组活动 – 描述性、综合 Second Set of Sessions – Descriptive, Combined
在描述性#2 栏位中，列出您将在描述性评估#2 (第2 天) 使用的咖啡，并包含您将用于标记每个
样品的代码。相同的咖啡将用于综合杯测 (第 2 天），并在综合栏位中，列出您在综合杯测中用于
标记每个样品的代码。In the DESCRIPTIVE #2 column, list the coffees you will use in Descriptive Assessment #2 (Day
2). Include the codes you will use to label each sample. The same coffees will be used in the Combined Cupping (Day 2). In
the COMBINED column, list the codes you will use to label each sample during the Combined Cupping.
