学员姓名：________________________________________________
测验日期：________________________________________________
第一部分
• 品尝九个杯子中的溶液，判断其味道是甜味、酸味或咸味。每种味觉类型各有三杯溶液。
• 接着判断该溶液的强度属于低、中或高等级。建议可使用「基本味觉溶液排列垫」将每杯溶液依序排列。
• 请将每个杯子的代码填入下方相对应的空格中：
味觉类型与强度 编 码
甜（低强度）
甜（中强度）
甜（高强度）
酸（低强度）
酸（中强度）
酸（高强度）
咸（低强度）
咸（中强度）
咸（高强度）
第二部分
• 品尝每一杯复合溶液。在「感受到的味觉」字段中，勾选实际体验到的味觉种类。接着，在「最强烈的味觉」
字段中，勾选一项该溶液中强度最高的味觉类型。
