## 🚀 快速安装

### 方法一：Git Clone

```bash
cd ~/.easyclaw/skills
git clone https://github.com/wlp0307/soe-coffee-master-skill.git "SOE COFFEE master skill"
```

### 方法二：下载 ZIP

1. 点击页面上方 **"Code"** → **"Download ZIP"**
2. 解压并重命名为 `SOE COFFEE master skill`
3. 移动到 `~/.easyclaw/skills/` 目录
4. 重启 EasyClaw

**详细安装指南**: [INSTALL.md](./INSTALL.md)

## 🎮 使用方法

安装后，直接提问即可：

```
推荐一款咖啡豆
手冲咖啡怎么冲？
北京哪里可以学咖啡？
```
