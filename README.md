## 📥 快速安装

### 方法1：直接下载（推荐）

1. 点击页面上方绿色按钮 **"Code"** → **"Download ZIP"**
2. 解压文件，重命名文件夹为 `SOE COFFEE master skill`
3. 移动到 Skills 目录：
   ```bash
   # Mac/Linux
   mv "SOE COFFEE master skill" ~/.easyclaw/skills/
   
   # Windows
   # 复制到 C:\Users\你的用户名\.easyclaw\skills\
   ```
4. 重启 EasyClaw 或刷新 Skills

### 方法2：Git Clone

```bash
# Mac/Linux
cd ~/.easyclaw/skills/
git clone https://github.com/wlp0307/soe-coffee-master-skill.git "SOE COFFEE master skill"

# Windows (PowerShell)
cd $env:USERPROFILE\.easyclaw\skills\
git clone https://github.com/wlp0307/soe-coffee-master-skill.git "SOE COFFEE master skill"
```

### 更新已安装版本

```bash
cd ~/.easyclaw/skills/SOE\ COFFEE\ master\ skill
```

## 🆘 常见问题

### Q: 下载很慢怎么办？
A: GitHub 在国内访问较慢，建议使用科学上网工具或 GitHub 镜像站。

### Q: 找不到 .easyclaw 文件夹？
A: 这是隐藏文件夹：
- **Mac**: 按 `Cmd + Shift + .` 显示隐藏文件
- **Windows**: 文件资源管理器 → 查看 → 勾选"显示隐藏的项目"

### Q: 解压后文件夹名称不对？
A: GitHub 下载会自动加 `-main` 后缀，需手动重命名为 `SOE COFFEE master skill`

### Q: 更新后还是旧版内容？
A: 需要重启 EasyClaw 或刷新 Skills 列表。

### Q: 如何确认是最新版本？
A: 询问 AI：
- "有多少款咖啡产品？" → 应该回答 33 款
- "CREMA 培训地址在哪？" → 应该回答朝阳公园南路6号
