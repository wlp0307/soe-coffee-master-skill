# SOE COFFEE Master Skill

## 简介

S.O.E COFFEE (八平方咖啡) 官方品牌助手 Skill，由创始人魏凌鹏老师授权开发。

### 功能特性

✅ **品牌咨询**
- 门店信息、产品推荐、电商渠道
- 骑士系列、瑰夏白白等明星产品介绍

✅ **培训服务**
- CREMA 咖啡培训课程体系介绍
- SCA 认证课程、Q-Grader 认证咨询

✅ **专业知识库**
- 内置 127+ 专业文件 (160MB+)
- **八平方品牌手册 2025** (16MB，最新版)
- SCA 专业培训体系 (咖啡师、冲煮、感官、烘焙、水质等)
- 智能索引系统，快速匹配相关知识

### 知识库覆盖

- **Barista 咖啡师** - 意式咖啡制作、拉花技术
- **Brewing 冲煮** - 手冲技术、萃取原理
- **Sensory 感官** - 杯测、风味识别
- **Roasting 烘焙** - 烘豆技术、烘焙度控制
- **Q-Grader** - 咖啡品质鉴定师认证
- **Water 水质** - TDS、硬度、矿物质管理
- **CVA** - 咖啡价值评估

### 使用场景

1. **产品咨询** - "推荐一款性价比高的咖啡豆"
2. **冲煮指导** - "手冲咖啡水温怎么控制?"
3. **专业学习** - "什么是 Q-Grader?"
4. **培训报名** - "CREMA 课程怎么报名?"

### 品牌理念

- **专业而温暖** - 用易懂的语言传递专业知识
- **敬畏自然** - 尊重咖啡从种子到杯子的旅程
- **Less is more** - 黑咖啡的纯粹美学
